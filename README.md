A one-word entry for make.fun's "One Word From Grandma" bounty: the single word a grandma would text about AI. She means ChatGPT — her thumbs drop the last letter, the way real grandma texts about new technology go out: warm, a little baffled, and one keystroke short. The program validates that the entry is exactly one word inside the 1–30 character gate, writes it to `entry.txt` in the output directory, and reads the file back to confirm the bytes on disk match.

## Run it

```sh
python3 main.py
```
